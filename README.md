# 盤遊館 — Classic Board Games SPA

GitHub Pages でそのままホスティング可能な、ビルド不要（Vanilla HTML5 / CSS3 / ES Modules JavaScript）のマルチボードゲーム SPA です。1クラス1ファイル構成で設計されており、新しいボードゲームも容易に追加できます。

## 収録ゲーム

| ゲーム | CPU対戦（初級・中級・上級） | 対人モード（ローカル2P） | 主な対応ルール |
| :--- | :---: | :---: | :--- |
| **オセロ** | ○ | ○ | 8×8標準、自動パス、上級はAlpha-Beta＋終盤完全読み |
| **囲碁** | ○ | ○ | 9/13/19路盤、自殺手・コウ禁止、中国ルール地合い計算、MCTS AI |
| **五目並べ** | ○ | ○ | 15×15、標準／連珠（黒の三三・四四・長連禁じ手）切替 |
| **将棋** | ○ | ○ | 9×9本将棋、成り・打ち駒・二歩・打ち歩詰め・千日手対応 |
| **チェス** | ○ | ○ | 8×8国際ルール、キャスリング・アンパッサン・昇格・50手・同形3回 |
| **4人麻雀** | ○（専用） | × | 半荘戦（東1〜南4）、赤ドラ、鳴き、リーチ、フリテン、役/符/点数計算、押し引きAI |
| **チェッカー** | ○ | ○ | 8×8、強制ジャンプ＆連続飛び越し、キング昇格、40手引き分け |
| **コネクトフォー** | ○ | ○ | 7列×6段重力四目並べ、上級7手Alpha-Beta探索 |
| **マンカラ** | ○ | ○ | カラハ標準ルール（3/4/5石選択可）、ピッタリ連続手番・横取り対応 |

## ローカル実行・テスト

```bash
# 単体テスト（Node.js 標準テストランナー）
npm test

# ローカル確認（任意の静的サーバーで起動）
python3 -m http.server 8080
```

## GitHub Pages 公開方法

1. このリポジトリを GitHub へプッシュします。
2. リポジトリの **Settings → Pages** を開き、Source に `main` ブランチの `/ (root)` を選択します。
3. ハッシュベースルーティング（`#/`, `#/game/<id>`）および相対パス構成のため、そのままサブパス配下で動作します。
